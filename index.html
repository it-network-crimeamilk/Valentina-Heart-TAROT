Функция предоставляет Пользователю одно предсказание в день. Выбранное предсказание и дата его открытия сохраняются в локальном хранилище браузера (localStorage) и не передаются на сервер. Очистка данных браузера приведёт к сбросу истории предсказаний.

1. Общие положения

Настоящая Политика конфиденциальности описывает, какие данные собирает сайт Valentina Heart TAROT (далее — «Сайт») и как они используются. Используя Сайт, вы соглашаетесь с условиями данной Политики.

2. Какие данные мы собираем

Сайт собирает только те данные, которые Пользователь предоставляет добровольно:

  • Имя и фамилия — указываются в форме заявки на расклад.
  • Контактные данные (телефон, e-mail, мессенджеры) — для связи по заявке.
  • Текст обращения — описание вопроса к раскладу.
  • Прикреплённые файлы — скриншот оплаты, фотография человека.
  • Данные отзывов — имя, текст отзыва, аватар (при загрузке).
  • Технические данные — cookies, IP-адрес, тип браузера (при использовании аналитики).

Сайт не собирает паспортные данные, номера банковских карт, данные медицинского характера и иную чувствительную информацию.

3. Локальное хранилище (localStorage)

Функция «Печенье с предсказанием» сохраняет в браузере Пользователя (localStorage) только идентификатор предсказания и дату его открытия. Эти данные:

  • не содержат персональной информации;
  • не передаются на сервер и не доступны Администрации;
  • могут быть удалены Пользователем в любой момент через настройки браузера.

Админ-панель использует sessionStorage для хранения временного флага авторизации. Эти данные удаляются при закрытии вкладки браузера.

4. Цели обработки данных

Персональные данные используются исключительно для:

  • обработки заявок и предоставления помощи;
  • связи с Пользователем по вопросам заказа и уточнения деталей;
  • публикации отзывов после модерации;
  • улучшения качества работы Сайта и анализа его посещаемости.

Мы не передаём персональные данные третьим лицам, за исключением случаев:
